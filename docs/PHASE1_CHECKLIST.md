## Архитектурные решения

### Networking
- **Non-blocking I/O** - fcntl(O_NONBLOCK)
- **poll() multiplexing** - одновременная обработка множества соединений
- **TCP sockets** - AF_INET + SOCK_STREAM
- **Graceful shutdown** - корректное закрытие всех ресурсов

### Memory Management
- **RAII pattern** - cleanup() в деструкторе
- **No leaks** - проверено valgrind/leaks
- **Smart cleanup** - закрытие FD перед delete
- **Clear ownership** - map<fd, Client*> для управления клиентами

### Error Handling
- **Exception safety** - try/catch в критических местах
- **Graceful degradation** - сервер не падает при ошибке клиента
- **Deferred cleanup** - безопасное удаление во время итерации
- **Error logging** - все ошибки логируются в stderr
