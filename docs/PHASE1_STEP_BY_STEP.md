## 🎯 ШАГ 1.1: Включить SO_REUSEADDR

### Статус: ⏳ ГОТОВ К ВЫПОЛНЕНИЮ

### Описание
Раскомментировать код для SO_REUSEADDR в `Server::initSocket()`.  
Это позволит перезапускать сервер без ожидания освобождения порта.

### Файл
`src/Server.cpp` - метод `initSocket()`

### Что сделать
Найти закомментированный код:
```cpp
// int opt = 1;
// if (setsockopt(_serverFd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt)) < 0) {
//     throw std::runtime_error("setsockopt(SO_REUSEADDR) failed: " +
//                             std::string(strerror(errno)));
// }
```

Раскомментировать:
```cpp
int opt = 1;
if (setsockopt(_serverFd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt)) < 0) {
    throw std::runtime_error("setsockopt(SO_REUSEADDR) failed: " +
                            std::string(strerror(errno)));
}
```

### Тестирование
```bash
# 1. Внести изменение
vim src/Server.cpp

# 2. Компилировать
make

# 3. Тест должен проходить
cd tests && make phase1

# Особое внимание на:
# [4/7] Testing rapid restart (SO_REUSEADDR)...
# ✓ Rapid restart works (SO_REUSEADDR enabled)
```

### Критерии успеха
